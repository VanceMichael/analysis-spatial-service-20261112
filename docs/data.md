# 数据与现有口径

visitors/served 为人数，x/y 为本地演练坐标，不对应真实人员位置。

`data/records.json` 是版本为 1 的演练数据，所有人员、机构、商品和交易均为本地合成记录。`id` 是导入记录键，不自动代表企业、访问或其他统计单位；记录键不得重复。数值字段必须有限，整数字段不得超过安全整数范围。空字符串可用于字段约定允许的未公开标签，不用零冒充缺测。

| 字段 | 类型 |
| --- | --- |
| `id` | `string` |
| `cell` | `string` |
| `district` | `string` |
| `visitors` | `integer` |
| `served` | `integer` |
| `x` | `number` |
| `y` | `number` |

现有 `summary` 按 `district` 清点记录，`sum` 为 `served` 的逐行核对值，不代表统计推断或跨期业务指标。分组按键排序，行按记录键稳定处理。`data/expected-summary.json` 是独立生成的现有核算对照；`data/policy.json` 保存业务配置的演练值，当前清点命令不消费分析配置。

`inspect` 返回输入行数、字段列表与 SHA-256 指纹；指纹不依赖字段或记录排列。数据版本不支持时应直接拒绝，不做静默迁移。错误发生时命令返回非零退出码。

## 空间集聚分析（cluster 命令）

`node src/cli.js cluster --config data/cluster.config.json --out var/cluster.json` 在本地完成空间自相关分析。机器可读结果走 stdout 并可落盘，简洁中文区域摘要走 stderr，同时写入 JSON 的 `chineseSummary` 字段。

### 指标口径必须先声明

分析前必须显式选择指标，不允许混用口径：

| `metric` | 含义 | 可估计条件 |
| --- | --- | --- |
| `count` | 服务次数计数（格网内 `served` 合计） | 总是可估计，零服务是合法的 0 |
| `rate` | 服务率（`served` 合计 / `visitors` 合计） | `visitors` 合计为 0 的格网**无定义**，列入 `excludedByMetric` 并说明原因，绝不按零服务率纳入 |
| `gap` | 需求缺口计数（`visitors` 合计 − `served` 合计） | 缺口为负（`served > visitors`）时口径不成立，标记无法估计 |

同一格网多行先聚合再计算；聚合时校验 `district/x/y` 一致。标准化值使用样本均值与总体标准差（除以 n）。

### 权重矩阵与结构质检

权重只来自本地邻接表（`weightsPath` 指向文件的 `edges`，默认复用 `data/policy.json`），不读取坐标。构建时检查并在 `weightDiagnostics` 中完整记录：自邻接（剔除计数）、重复有向边（保留首条并计数）、不对称边（只报告不补边）、悬空引用（直接拒绝）、孤岛（无任何邻居）。`standardization` 取 `row`（每行权重归一为 1）或 `raw`（保留原始边权）。`radii` 支持多个邻接半径：半径大于 1 时在无向化基础图上 BFS 派生，仅支持单位边权，避免擅自设定距离衰减。

### 全局与局部 Moran's I

- 全局 Moran's I 衡量整体空间自相关，同时给出解析零假设期望 `−1/(n−1)` 与置换分布。
- 局部 Moran's I 给出每个单元的集聚类型：`HH` 高-高（热点）、`LL` 低-低（冷点）、`HL`/`LH` 高低异常，未通过显著性的单元记为 `NS`。
- 显著性只用与零假设一致的条件置换估计，双侧 p 值采用 `(≥观测的伪值数 + 1)/(置换数 + 1)`，因此最小 p 值为 `1/(R+1)` 而不会出现零。
- **全局置换**固定指标多重集在全部位置重排；**局部条件置换固定焦点单元自身取值**，仅在其余位置重排，每个焦点使用由 `(seed, scope, cell)` 派生的独立随机流，不能把全局打乱复用为局部检验。小样本（参考池 ≤ 7）可设 `exact: true` 走全排列枚举。
- 两种置换范围回答不同问题：`city`（全市）回答相对全市分布是否异常相似；`district`（区县内）只在同区县格网间重排，跨区县邻居保持观测值，剔除区县间整体水平差异。区县内置换参考池不足时该单元标记无法估计，不回退到全市结果。
- 岛状格网与有效邻居不足（`minNeighbors`）的单元在全局与局部结果中都显示无法估计及原因，不产出伪指标。
- 每个局部检验家族（一个半径 × 一个置换范围）同时给出原始 p、Bonferroni 与 Benjamini-Hochberg FDR 调整值及家族大小；探索过的全部半径、指标、置换范围与全部单元都登记在 JSON 中，不挑选最漂亮的地图。
- 每个热点输出邻居清单（含权重与邻居标准化值）、自身标准化值、局部 I、置换范围、参考池、随机流种子与置换次数供复核。
- `sensitivity` 段对比各邻接半径的全局 I、邻居度分布、聚类计数与每个显著单元的跨半径分类轨迹；对邻接定义敏感的分类应下调走访优先级。

### 结论边界

空间集聚只反映指标取值的空间自相关。低值连片可能由访客偏少造成，输出中固定附带不作资源不足因果结论的提醒，热点/冷点仅用于提示值得实地走访的片区。
